# 周复盘说明

这个文件说明学习者如何复盘，但不代替学习者填写复盘。实际记录由学习者自行放入空的 `journal/` 目录。

## 建议结构

```text
本周目标：
实际完成：
留下的产出：
使用了什么验证方法：
最重要的错误或误解：
哪种练习有效，证据是什么：
哪种练习无效，原因可能是什么：
仍无法解释的问题：
下周唯一优先目标：
```

## 复盘标准

- 记录证据，不写“感觉学会了”。
- 同时记录有效和无效尝试。
- 把问题缩小到下一步可以验证的程度。
- 不用学习时长、连续天数或文件数量代替能力进步。
- 下周目标应对应当前阶段出口标准。

## 何时调整路线

- 连续两次未通过同一验收：拆小任务或补前置知识。
- 任务全部通过但速度慢：先确认质量，再逐步增加约束。
- 计划频繁延期：采用学习计划中的最小可执行路线。
- 目标发生变化：更新学习总图，不必为了完成旧清单继续学习无关内容。
