# 书籍与长资料阅读顺序

长资料用于解决具体问题，不以“全部读完”为目标。

## 后续阶段

按阶段列出真正有用的长资料。不要把同一资源重复列入多个阶段；引用它即可。

## 使用规则

- 先带着问题查阅，再回到实践验证。
- 不将页数或视频时长作为主要学习成果。
- 不收录盗版、泄露内容或无法确认来源的下载链接。
- 对可能更新的在线资料标明访问日期。
