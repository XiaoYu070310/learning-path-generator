# Quality Checklist

Use this checklist after generation and before reporting completion.

## Learner fit

- [ ] The learner profile and assumptions are explicit.
- [ ] The route starts from the learner's actual background.
- [ ] The final goal is a demonstrated capability, not a vague topic label.
- [ ] Time estimates are ranges and fit the stated weekly budget.
- [ ] A shorter route exists for busy periods where appropriate.

## Structure

- [ ] `00_先看我` gives a clear map and today's first action.
- [ ] `01_资料使用顺序` distinguishes required, optional, and lookup material.
- [ ] Environment/tools guidance fits the domain.
- [ ] Phase names and order match across all root documents.
- [ ] Detailed documents are linked rather than duplicated.
- [ ] Relative links resolve.
- [ ] Every listed file exists.

## Learning design

- [ ] Each phase has prerequisites, goals, practice, evidence, and exit criteria.
- [ ] Practice progresses from small feedback loops to independent work.
- [ ] Acceptance criteria are observable and domain-appropriate.
- [ ] Correctness or quality precedes speed, scale, or polish.
- [ ] Optional tracks do not obscure the required spine.
- [ ] Recovery advice exists for failed checks.

## Learner ownership

- [ ] `projects/` exists and is completely empty.
- [ ] `journal/` exists and is completely empty.
- [ ] No personal training files were copied.
- [ ] No completed exercises, solutions, fake results, or filled reviews are presented as learner work.
- [ ] Practice specifications live outside learner directories.

## Accuracy and currency

- [ ] Current facts were researched or clearly marked for verification.
- [ ] Official sources are preferred for rules, versions, and syllabi.
- [ ] URLs, commands, and versions were not invented.
- [ ] Platform-specific guidance is labeled.
- [ ] Claims and thresholds are qualified.
- [ ] Sources include access dates where freshness matters.

## Distribution quality

- [ ] No credentials, private data, personal names, or absolute personal paths remain.
- [ ] No copyrighted books, paid courses, leaked exams, or unlicensed assets are bundled.
- [ ] No unnecessary installers, archives, binaries, build directories, or duplicate renders are included.
- [ ] Templates contain no unresolved placeholders.
- [ ] The package can be understood without access to the original source directory.

## Validation

- [ ] `validate_learning_package.py` exits successfully.
- [ ] Every warning was reviewed.
- [ ] The completion report names the first file and first action.
